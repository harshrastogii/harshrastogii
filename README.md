I'm a data scientist in Darwin. I build tools from open Northern Territory data on fire, climate, biodiversity, connectivity and public services, and I put them online so councils, researchers and community groups can use them. Before this I worked in treasury and reconciliation, which is where I learned to ask what a number is for before calculating it.

I'm finishing a Master of Data Science at Charles Darwin University and I lead GovHack in the NT. I'm open to data science roles, and to project work with researchers, councils and not-for-profits.

## How I work

- I start from the decision the analysis is meant to inform, then go looking for data.
- I finish with something people can open. Every project here has a live site or a public repo.
- I report what the data doesn't support. The biodiversity surrogates were only modestly useful, and Conflux's two detectors disagreed. Both results are published.
- I build things that keep running on their own: scheduled pipelines, no servers to look after.

## Tools

Python, SQL and pandas for analysis. scikit-learn, PyTorch and TensorFlow for models. GeoPandas, Earth Engine, MapLibre GL and Leaflet for spatial work. Next.js, React, FastAPI, Streamlit and Panel for the apps, and GitHub Actions, Cloudflare Workers and Vercel to keep them running.
